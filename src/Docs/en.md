# Prayer Times Package

Accurate prayer times calculation and display package for Bagisto Admin and Storefront.

## Features
- Precise offline calculation for all five daily prayers plus sunrise and midnight.
- Full configuration of geographic coordinates (latitude and longitude), timezone offset, and calculation methods.
- Support for major global conventions: Muslim World League, Umm al-Qura, Egyptian General Authority of Survey, Islamic Society of North America (ISNA), and University of Islamic Sciences Karachi.
- Responsive widgets for storefront and admin dashboard.

## Configuration
Access configuration under:
Admin Panel > Settings > Configuration > Prayer Times.
